# Design System

## Theme Overview

This document outlines the core visual theme for our applications. It's built upon a foundation of modern design principles, focusing on clarity, consistency, and user experience.

### Color Palette

Our color palette is defined to ensure accessibility and brand consistency.

*   **Primary Color:** `#004B7C` - This deep blue signifies trust and professionalism, used for primary actions and key brand elements.
*   **Secondary Color:** `#00A896` - A vibrant teal, offering a refreshing contrast for secondary actions and highlights.
*   **Neutral Color:** `#F8F9FA` - A light, almost white, background color providing a clean canvas for content.

### Typography

We employ a thoughtful typographic scale to establish hierarchy and readability.

*   **Headlines:** `manrope` - A modern sans-serif typeface, offering strong readability for titles and headings.
*   **Body Text:** `inter` - A highly legible and versatile sans-serif for all main content.
*   **Labels:** `inter` - Consistent with body text for clarity in interactive elements.

### Shape and Form

Our UI elements are designed with a **moderate roundedness (2)**, striking a balance between modern aesthetics and approachability. This provides a subtle softness to components without being overtly playful or overly sharp.

### Spacing

We maintain a **normal level of spacing (2)** between UI elements, ensuring a balanced visual density that is neither too compact nor excessively spacious. This promotes good readability and visual organization without wasting screen real estate.
